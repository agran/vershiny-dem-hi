# vershiny-dem-hi

Детальный DEM-слой (~87 м) для проекта [Вершины / Vershiny](https://github.com/agran/vershiny) —
open-source PWA-аналога PeakFinder. Раздаётся через GitHub Pages этого репозитория.

Дополняет базовую глобальную пирамиду [vershiny-dem](https://github.com/agran/vershiny-dem)
(217 м / 435 м / 1.7 км): здесь лежит родное разрешение исходника там, где люди реально стоят
с телефоном, — горные регионы приоритета 1–3 из реестра приложения целиком, плюс самые
горные ячейки приоритета 4 по остатку бюджета (Анды, Гималаи, Аляска, Тибет, Гиндукуш).

## Данные

**Copernicus DEM GLO-90**, © DLR/ESA — свободная лицензия с атрибуцией.
Исходники: AWS Open Data `s3://copernicus-dem-90m/` (Cloud-Optimized GeoTIFF 1°×1°).

## Структура

```
tiles/hi/0/{x}/{y}.bin.gz   256×256 int16 LE, дельта по строкам, gzip
tiles/hi/index.json         bbox, уровень, квант, битсет покрытия
```

| LOD | Ячейка | Тайл | Что покрывает |
|---|---|---|---|
| 0 | ~87 м (N=1280) | 0.2° | p1–p3 целиком (1130 ячеек 1°) + верхушки p4; 31 300 тайлов, ~957 МБ |

Высоты: значения int16 = `h / quantM` (квант 2 м — 1 м тонет в шуме GLO-90),
дельта-кодирование вдоль строк, gzip. Клиент распаковывает `DecompressionStream`.

Грубого фолбэк-уровня (1.7 км) здесь нет: в дырах разреженного LOD 0 клиент
уходит на базовую пирамиду vershiny-dem, где тот же уровень уже есть —
дубль был мёртвым грузом.

## Сборка

Генератор — в основном репозитории: `tools/dem-pipeline.py` (обе пирамиды
одной командой) или напрямую `tools/glo90-to-tiles/glo90_to_tiles.py`:

```powershell
python tools\glo90-to-tiles\glo90_to_tiles.py build --only-priority 1,2,3,4 `
  --levels "1280:2:100:1.0" --budget-mb 950 -o ..\vershiny-dem-hi\tiles\hi --clean
```

⚠️ Доля уровня `1.0` в `--levels` обязательна: `-` означает «без лимита»,
и `--budget-mb` тогда не действует вообще.

История репозитория — один коммит: пересборка перезаписывает все бинарники,
и полная история удвоила бы размер сверх лимита GitHub Pages (1 ГБ).
